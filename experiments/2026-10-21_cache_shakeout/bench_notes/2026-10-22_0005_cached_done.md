    lengths were not measured.
- **The pilot's slow MTG builds were first-touch costs.** MTG contrastive
  built at 3.5–6.7 ms per card in the pilot and 0.6–1.15 ms here. This
  run also has 10× more builds.
- **`build_dojos` was 43% faster than in the pilot** (1,813 vs 3,164 s),
  with no code change. Probably the OS file cache was warm after the
  pilot, but this was not measured. Startup cost should be quoted as
  "30–53 min" until a cold start is timed.
- **The RAM tier never served a hit.** Every cacheable text fits in the
  VRAM tier, at 5% of its row capacity, and the disk tier only fed the
  warm-up.
- **Data exposure** (2,956 steps/h, real diet):
  - Some dojos cycle their TRAIN set within an hour:
    - `contrastive*.pokemon` (159 decks) repeats every 2–6 minutes,
      237–719 passes in 24 h.
